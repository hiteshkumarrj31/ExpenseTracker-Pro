What's inside this project

ExpenseTracker Pro

A personal finance management web app built with plain HTML, CSS and JavaScript — no framework, no backend. All data lives in your browser's LocalStorage, so the app works fully offline and keeps your financial data private.

Tech Stack

  • HTML5, CSS3, vanilla JavaScript (ES6)
  • Bootstrap 5.3 + Bootstrap Icons
  • Chart.js for data visualization
  • LocalStorage as the data layer

Future Scope

  • User login & cloud sync (Firebase)
  • Monthly budget planner & alerts
  • Recurring transactions
  • Financial goals with progress tracking
  • OCR receipt scanning
  • Native mobile app

Privacy

This app makes no network requests for your financial data. Everything you add stays in this browser's LocalStorage until you export or clear it yourself.
